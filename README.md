# Gunjan Chakrabartty — Portfolio

Personal portfolio site: cybersecurity, ethical hacking, and machine learning work.

Built with Vite, React 19, Tailwind CSS 4 and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Opens on http://localhost:5180.

## Build

```bash
npm run build
```

Static output goes to `dist/`, ready for any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
